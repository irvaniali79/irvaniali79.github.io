# irvaniali79.github.io

A personal resume / portfolio built from the original vanilla HTML/CSS/ES-module project.

## What changed

- Reframed the page as a personal engineering profile instead of a generic CV card.
- Kept the original stack: vanilla HTML, CSS, and ES modules.
- Kept content data-driven through `assets/db/store.js`.
- Added sections for About, Experience, Capabilities, Projects, Notes, and Contact.
- Added scroll-spy navigation, mobile navigation, note filtering, and print/PDF support.
- Reused the original workspace and profile imagery, with smaller web-optimized copies for the page.

## Run

The project is static. Open `index.html` directly or serve the directory with any static server.

For Sass development, the existing project script remains available:

```bash
npm run sass
```
